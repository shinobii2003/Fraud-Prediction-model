# Fraud-Prediction-model

## Objective
To identify fraudulent transactions using machine learning on an imbalanced dataset.

## Approach
- Data cleaning and preprocessing
- Exploratory data analysis
- Handling class imbalance
- Model building using XGBoost
- Evaluation using precision, recall, and F1-score

## Key Insights
- High recall achieved for fraud class
- Precision-recall trade-off analyzed
- Model suitable for real-world fraud detection scenarios

## Tools Used
Python, Pandas, Scikit-learn, XGBoost
